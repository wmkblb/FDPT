# FDPT: Frequency-Decoupled Prompt Tuning for Vision-Language Models

This repository contains the official implementation of:

**Frequency-Decoupled Prompt Tuning for Vision-Language Models**

FDPT addresses the base-to-novel trade-off in vision-language model adaptation by decoupling low-frequency semantic cues and high-frequency discriminative cues during prompt optimization.
